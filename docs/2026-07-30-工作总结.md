## 今日完成事项

### 1. 修复实用下载栏目 404 bug

**问题**：用户反馈点击下载按钮报"无法从网站上提取文件"，所有 10 个文件均无法下载。

**根因**：`.gitignore` 配置了全局排除规则：

```
*.docx
*.doc
*.xlsx
*.pdf
*.rar
```

导致 `downloads/` 目录下的所有文件从未被 git 追踪、从未推送到线上仓库。GitHub Pages 服务器上根本没有这些文件，访问即 404。

**修复**：
- 在 `.gitignore` 中添加例外规则，允许 `downloads/` 子目录下的文件被追踪：

  ```
  !downloads/**/*.docx
  !downloads/**/*.doc
  !downloads/**/*.xlsx
  !downloads/**/*.pdf
  !downloads/**/*.rar
  ```

- 将 10 个下载文件加入 git 并推送至 GitHub

### 2. 同步 GitHub 远程仓库

修复提交最初只推送到了 Gitee，漏掉了 GitHub（`origin`）。用户实际使用的是 GitHub Pages，补充推送后问题解决。

---

## 教训

- `.gitignore` 全局通配符会影响所有子目录，新增子目录文件时需检查是否被意外排除
- 多 remote 场景下推送时需确认目标是否正确
