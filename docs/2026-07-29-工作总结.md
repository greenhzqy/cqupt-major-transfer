## 技术说明

- 纯静态 HTML 单文件网站，部署于 GitHub Pages / Gitee Pages

- 图表使用 Chart.js CDN（`chart.js@4.4.7`）
- 图标使用 Font Awesome CDN（`fa-solid/fa-brands`）
- `downloads/` 目录下的文件通过 `.gitignore` 例外规则上传至 Git 仓库，其余位置的二进制文件仍被排除
