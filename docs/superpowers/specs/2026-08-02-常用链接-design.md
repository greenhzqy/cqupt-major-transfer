# 常用链接标签页 — 设计说明

**日期：** 2026-08-02
**状态：** 已确认

---

## 需求

学弟反馈网站需要添加常用网站链接。确定新增独立标签页，首期放 3 个链接，后续可扩展。

| 名称 | URL | 图标 |
|------|-----|------|
| 学校官网 | https://www.cqupt.edu.cn/ | fa-school / fa-building-columns |
| 教务在线 | https://jw.cqupt.edu.cn/ | fa-file-lines / fa-calendar-check |
| 抖音主页 | https://v.douyin.com/aP6j5SydZhA/ | fa-brands fa-tiktok |

## 页面结构

```
🔗 常用链接 标签页
├── 提示条（alert-info）
│   └── ⚠️ 教务在线等校内网站需连接校园网或通过 VPN 访问
├── 链接卡片区（1 个 card 分组，便于后续扩展）
│   ├── 学校官网 卡片
│   ├── 教务在线 卡片
│   └── 抖音主页 卡片
```

## 卡片样式

- 复用现有 `.dl-card` 布局：左侧图标 + 中间标题描述 + 右侧箭头
- 整张卡片用 `<a>` 包裹，`target="_blank"` 新窗口打开
- 悬停效果：上浮 + 阴影加深（已有 `.dl-card:hover`）
- 3 张卡片用 `.grid-2` 或 `.grid-3` 自适应网格排列

## 扩展预留

- 每个分组是独立的 `.card` 容器，`.card-header` 为类别标题
- 目前只有一个分组「常用链接」，后续加「学院官网」等仅需新增 `.card` 区块
- 卡片数据用 JS 数组驱动或直接 HTML，初期直接写 HTML 保持简单

## VPN 提醒

教务在线是校内系统，校外访问需 VPN。顶部加 alert 提示条，样式用现有 `.alert.alert-info`。

## 导航变更

导航栏新增第 9 个 tab 按钮：`<i class="fa-solid fa-link"></i> 常用链接`
