# 重邮转专业知识库

重庆邮电大学(CQUPT)本科生转专业信息汇总网站。整合了2023-2026年的转专业计划人数、各学院考核录取方案、学生攻略和实际录取数据。

## 使用方法

1. 直接在浏览器中打开 `index.html` 即可浏览
2. 网站是纯静态页面，无需服务器，可离线使用（图表需要网络加载 Chart.js CDN）
3. 顶部导航栏切换7个主要板块

## 网站板块

| 板块 | 内容 |
|------|------|
| **总则** | 转专业基本流程、核心概念词典、通用报名条件 |
| **学院详情** | 14个学院的详细信息：门槛、历年人数、考核方式、攻略点评 |
| **历年数据** | 2023/2025/2026年各学院计划接收人数完整表格及对比图表 |
| **考核方案** | 2026年13个学院的完整考核录取实施方案 |
| **转专业攻略** | 学生编写的完整攻略（基于2022及2024年情况） |
| **数据统计** | 2024-2025学年预录取233人数据可视化 |
| **实用下载** | 转专业审批表、课程认定表等说明 |

## 数据来源

所有数据来源于以下官方和非官方文件：

- `重邮转专业攻略2025版.docx` — 学生编写的转专业攻略
- `2023年各学院转专业计划接收人数329.docx` — 2023年官方计划
- `2025年各学院本科生转专业计划接收人数(1).docx` — 2025年官方计划
- `附件1.各学院2026年转专业计划接收人数表.pdf` — 2026年官方计划
- `附件2.各学院2026年本科生转专业考核录取实施方案.pdf` — 2026年考核方案
- `2024—2025学年第二学期转专业预录取学生名单公示.xlsx` — 实际录取数据
- `学院转专业考核录取办法.rar` — 2025年各学院考核办法
